# FT8YO fixed Android app

Download **FT8YO-0.93-trUSDX-USB-retry-fix3-debug.apk** from this directory.

This is the tested side-by-side debug build. It enables receive audio with
`UA1;`, retries stream startup after the USB port becomes ready, and contains
the fragmented `(tr)uSDX` stream-marker fix. Its Android package name is
`com.bg7yoz.ft8cn.trusdxfix`, so it can be installed alongside the original
FT8CN app.
